Place your own media files here:

- my-cat.png          -> photo of the cat (transparent PNG works best), shown in the "My Precious Companion" section
- gallery1.jpg         -> gallery photo 1
- gallery2.jpg         -> gallery photo 2
- gallery3.jpg         -> gallery photo 3
- birthday-music.mp3   -> background birthday music (MP3)

If any file is missing, the website automatically shows a pretty illustrated
placeholder instead of a broken image, so the site never looks broken.
See the main README.md for full instructions.
